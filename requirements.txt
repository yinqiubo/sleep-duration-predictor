# 云端上线专用依赖（固定版本，与本地实测环境一致，保证 models/*.pkl 能正常反序列化）
#
# 本地实测（Windows + Python 3.13.5，2026-10-04）：
#   pandas 2.2.3 / numpy 2.4.6 / scipy 1.18.0 / scikit-learn 1.6.1 / joblib 1.4.2
#   streamlit 1.45.1 / matplotlib 3.10.0 / tabulate 0.9.0
#
# ⚠️ 云端 Python 版本必须显式选 3.13（次选 3.12），【不要用默认的 3.14】：
#   上面这些版本都发布于 Python 3.14 出现之前，没有 cp314 预编译 wheel，
#   云端只能从源码编译 scikit-learn / pandas / matplotlib，表现为日志卡在
#   "Processing dependencies..." 十几分钟直到被超时回收，或者装不上 sklearn、
#   运行时直接 ModuleNotFoundError: No module named 'sklearn'。
#
# 用法（Streamlit Community Cloud）：在云端仓库里用本文件覆盖根目录 requirements.txt；
# 步骤原记在 `deploy/README.md` 第 5 节（该目录已从交付包剔除），替代说明见 README 第 1.3 节。
# 原因是模型是用 sklearn 1.6.1 训练的，云端装到不同大版本可能出现 InconsistentVersionWarning
# 甚至反序列化失败；固定版本可以完全避免这一类"云端才报错"的问题。

pandas==2.2.3
numpy==2.4.6
scipy==1.18.0
scikit-learn==1.6.1
joblib==1.4.2
streamlit==1.45.1
matplotlib==3.10.0
tabulate==0.9.0
